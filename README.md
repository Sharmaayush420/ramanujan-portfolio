# Srinivasa Ramanujan Portfolio Website

A responsive single-page portfolio created for the Web Application Development assignment using **HTML5 and external CSS3 only**. No JavaScript or framework is required.

## Assignment requirements included

- Header with Ramanujan's name, portrait, and designation
- About section of approximately 170 words
- Education table
- Six major contributions
- Awards and achievements
- Gallery with three images
- Contact form
- Footer with student-detail fields
- External stylesheet, headings, paragraphs, hyperlinks, images, lists, table, borders, rounded corners, Flexbox, and responsive media queries

## Files

- `index.html` — all page content and semantic HTML5 structure
- `style.css` — external stylesheet and responsive layout
- `.nojekyll` — tells GitHub Pages not to run a Jekyll build for this static project

## Before submitting

1. Open `index.html` in a code editor.
2. In the footer, replace `[Enter your name]`, `[Enter your enrollment number]`, and `[Enter your department]` with your own details.
3. In the contact form, change `your-email@example.com` to an email address you can access. A `mailto:` form typically opens the visitor's email application; it does not store or send messages through a website server.
4. Open the website in a browser and confirm that the sections and images display correctly. The three photographs are loaded from Wikimedia Commons, so an internet connection is needed to display them.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new public repository**. A simple name is `ramanujan-portfolio`.
2. Extract the ZIP file on your computer.
3. In the repository, select **Add file → Upload files**. Upload `index.html`, `style.css`, `.nojekyll`, and `README.md` from the extracted folder. Make sure `index.html` is at the repository root, not hidden inside another folder.
4. Add a commit message such as `Add Ramanujan portfolio website` and click **Commit changes**.
5. In the repository, open **Settings → Pages**.
6. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait for the Pages deployment to complete. The URL will be similar to `https://YOUR-USERNAME.github.io/ramanujan-portfolio/`. Your actual username and repository name determine the exact link.
9. Open the URL and test the navigation links, table, images, and contact form. GitHub Pages may take several minutes to publish the first time.
10. Copy the published URL into Google Classroom and upload the same project ZIP as the source-code submission.

Official guide: https://docs.github.com/en/pages/quickstart
